# 2020 days 1–6: oracle provenance

The input fixtures are byte-for-byte copies from [the original repository at 6522adb](https://github.com/jacoelho/advent-of-code/tree/6522adb786cf29d1322d193234698ed2c429b89b/2020/inputs). [Recorded answers and SHA-256 hashes](2020-days01-06-oracles.json) identify the exact data. The F# source has no stored answer assertions. Expected answers were calculated independently with Python, before running the Go implementations; they are not accepted-answer receipts from Advent of Code.

Public puzzle pages expose part one. Part-two semantics were cross-checked against source implementations and independently worked examples. Tests retain literal expected results and exercise the `io.Reader` solver boundary rather than copying production algorithms.

Two F# defects were corrected instead of preserved: day 3 counts distinct boolean groups rather than trees, and day 4's function named `Part1` implements part-two field validation. Go provides separate field-presence and strict-validation answers. Passport tests distinguish the two policies and cover numeric widths, colour syntax, and height bounds.

Further regressions cover distinct expense entries, positional XOR, boarding-pass decoding and an interior gap, final-group flushing, malformed input, and reader failure propagation. Both new parts of each day pass with the original input and canonical examples.
