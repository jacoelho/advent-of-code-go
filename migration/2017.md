Existing scanner, numeric conversion, grid, set, deque, stack and graph-search helpers are reused. Entry points and tests follow the 2023/2024 package conventions, with ordinary multiline functions and whitespace between logical blocks. Comments explain non-obvious constraints.

The first twelve days use direct scans, indexed mutation, complete cycle states, subtree totals, a stream state machine, cube coordinates and graph traversal. ### Exact particles

Twice one particle coordinate at time `t` is `a*t² + (a+2v)*t + 2p`. Its eventual sign is the first nonzero coefficient's sign. Summing sign-adjusted coefficients across coordinates gives a lexicographically comparable eventual Manhattan-distance polynomial. Equal polynomials retain the first input index.

For each pair, solve one nonidentity coordinate equation, then verify each integer root against all three coordinates. Keep the earliest common nonnegative time: after that event at least one member has been removed, so later intersections of the same pair cannot remove additional survivors. All pairs at one time are inspected before removals are applied. Arbitrary-precision integers cover coefficient construction, discriminants and times, including times beyond `int64`.

Initial collisions count (`t >= 0`). This interprets “positions ever exactly match” as including the initial snapshot; it is not claimed as an official worked-example boundary. [Jasper Van der Jeugt's solution](https://github.com/jaspervdj/advent-of-code/blob/master/2017/20.hs) and [JP Verkamp's simulator](https://blog.jverkamp.com/2017/12/20/aoc-2017-day-20-miniature-universe-simulator/) inspect the initial positions. The real input has no initial duplicates. Its exact event times lie between 10 and 39, with 648 survivors; the eventual closest particle is 243.

### Verified coprocessor shortcut

The full thirty-two-instruction program establishes that `h` counts composite numbers in an inclusive arithmetic progression. Only five immediate parameters may differ from the recognized template. Checked prefix execution derives the endpoints; the guard requires positive stride, reachable endpoint, values at least three, and no overflow in the literal nested multiplication. In particular, `(end-1)²` must fit `int64`.

For the original input the progression is 106700 through 123700 at stride 17: 1001 candidates and 905 composites. Trial division uses `divisor <= value/divisor`. Other programs run through the bounded checked interpreter. A reduced template over 3 through 7 returns two; changing only the `h` increment returns four through literal execution. ## Bounds and failure behavior

Resource limits return errors, never partial answers. The firewall searches at most 100 million delays; an exhausted complete period proves impossibility, while a larger period yields an explicit search-limit error. Duet execution permits fifty million steps and one million queued values per process. Particle analysis permits two thousand particles, bounding pair events to 1,999,000. Fractal expansion permits eighteen rounds; virus simulation permits ten million bursts. Coprocessor interpretation and composite counting each permit ten million operations. Bridge search permits sixty-four physical components and one million memoized states. Turing simulation permits one hundred million transitions. Finite puzzle grids, fixed-round hashes and generators have input- or puzzle-derived bounds.

Numeric parsing rejects overflow and malformed values. Assembly arithmetic and jumps preserve overflow errors. Undefined blueprint states, conflicting fractal rules, ambiguous tube turns and invalid bridge strengths fail explicitly. A shared test covers reader-error propagation through all 49 entry points.
