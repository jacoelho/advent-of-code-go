# 2020 days 7–19

Both parts of these thirteen days are implemented, completing all 49 puzzle parts for 2020. The input files and source behavior came from [the original F# repository at 6522adb](https://github.com/jacoelho/advent-of-code/tree/6522adb786cf29d1322d193234698ed2c429b89b/2020). Fixtures are copied byte-for-byte, except day 15: its inline seed `0,8,15,2,12,1,4` is now a text fixture.

## Independent expectations

QA calculated each expected answer with a separate Python implementation before the Go solutions ran. [Answers and fixture hashes](2020-days07-19-oracles.json) record the data. These are independently checked results, not accepted-answer receipts from Advent of Code. The oracle uses exhaustive VM flips, integer combinations and contiguous ranges, synchronous seat sets, complex-number navigation, modular-inverse CRT, direct floating-address enumeration, sparse neighbour counts, operator stacks, and memoized grammar offsets. It shares no Go implementation code. The source input has one boot-code repair, one XMAS weakness window, and one ticket-field assignment.

Canonical examples and literal small regression expectations provide a second check where the most natural algorithm is similar. Tests use the solver boundary, with narrowly parameterized helpers for the XMAS preamble and memory-game turn count. Both parts of all thirteen days also propagate injected reader errors.

## Source corrections

- Day 8 terminates only at the instruction immediately after the program; jumping beyond it is an error.
- Day 9 derives the invalid target from its input instead of embedding the author's answer. A valid preamble pair requires different values, as the [puzzle states](https://adventofcode.com/2020/day/9). A weakness range has at least two entries.
- Day 13 correctly returns zero waiting time for an exact departure, retains nonzero offsets for the first active bus, and handles compatible shared factors.
- Day 15 preserves earlier occurrences when the final starting value is duplicated.
- Day 16 selects a `departure` prefix, excludes invalid nearby tickets, and explicitly rejects inconsistent or ambiguous assignments.
- Day 18 consumes the entire expression and rejects unbalanced parentheses, missing operands, invalid operators, and integer overflow.

## Algorithms and reference comparisons

Day 7 uses graph reachability and memoized bag quantities. Day 8 tries each single-instruction repair; no framework or mutable program copies are required. Day 9 uses a prefix-sum lookup for the contiguous range. Day 10 uses adapter-path dynamic programming, including two-jolt gaps. Day 11 precomputes seat neighbours and updates occupancy synchronously. Day 12 uses integer coordinates and quarter-turn rotations. [Zelark's day 10](https://github.com/zelark/AoC-2020/blob/master/src/zelark/aoc_2020/day_10.clj) and [navigation examples](https://github.com/zelark/AoC-2020/blob/master/src/zelark/aoc_2020/day_12b.clj) supported the direct DP and coordinate representations.

Days 13–17 were compared against [the collected Scala solutions](../reference/.repos/maneatingape--advent-of-code-scala/src/main/scala/AdventOfCode2020). CRT avoids a period-by-period search for day 13. Day 15 stores last-seen turns in one fixed-size array, with a separate small map only for oversized seed values. Day 16 uses deterministic bipartite matching and tests uniqueness by excluding each matched edge; it does not rely on singleton propagation completing. Day 17 keeps only active coordinates and neighbour counts. These implementations do not claim measured speedups over the references.

Two choices received an independent advisor review:

- **Day 14:** Symbolic address cubes support all 36 floating bits without enumerating individual addresses. Reverse processing and cube subtraction preserve overwrite semantics, including zero writes. Valid totals can exceed 64 bits, justifying `big.Int`. Cube fragmentation can still grow for adversarial write sequences; this method avoids address enumeration but does not guarantee small memory use for every possible program. Tests cover complete and partial overlap, zero values, and an all-floating mask.
- **Day 19:** An Earley chart tracks deduplicated partial matches at each input position. It handles recursive and ambiguous rules without a depth cutoff or an assumed width for rules 42 and 31. Empty alternatives are rejected, so completed rules consume input and the completion loop has a clear invariant. The [Clojure reference](../reference/.repos/tschady--advent-of-code/src/aoc/2020/d19.clj) delegates to a parser library; the [Scala reference](../reference/.repos/maneatingape--advent-of-code-scala/src/main/scala/AdventOfCode2020/Day19.scala) assumes fixed-width chunks. The Go chart avoids either dependency. Tests cover exact consumption, three alternatives, ambiguous derivations, left recursion, unit cycles, and nesting beyond a small fixed limit.

Day 18 uses one precedence-climbing evaluator with an addition precedence of one or two. Unlike the [Scala reference's token/postfix pipeline](../reference/.repos/maneatingape--advent-of-code-scala/src/main/scala/AdventOfCode2020/Day18.scala), it needs no intermediate token or syntax-tree representation. Its independent oracle uses operator stacks.
